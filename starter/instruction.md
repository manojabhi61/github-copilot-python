# GitHub Copilot Instructions

## Project Overview
Refactor the legacy Flask Sudoku application while preserving existing functionality and implementing the required project features.

## Coding Guidelines
- Follow Python PEP 8.
- Write clean, modular, and reusable code.
- Keep functions small and focused.
- Avoid duplicate code.
- Add comments where necessary.
- Use consistent error handling.
- Preserve existing functionality unless implementing a required feature.

## Testing Guidelines
- Use pytest as the testing framework.
- Ensure all tests pass before and after refactoring.
- Do not modify application behavior unless required.

## Required Features
- Difficulty selector (Easy, Medium, Hard)
- Unique solution validation
- Locked prefilled cells
- Invalid move highlighting
- Completion message
- Hint button
- Check button
- Timer
- Dark mode
- Top 10 leaderboard using local storage

## Copilot Guidelines
- Explain suggested changes before applying them.
- Suggest incremental changes instead of large rewrites.
- Preserve compatibility with the existing Flask application.
